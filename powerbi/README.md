# Datify AI - Power BI Integration

This directory contains the cleaned, aggregated dataset ready for Business Intelligence workflows.

## Workflow Instructions

1. **Import the Dataset**: 
   Open Microsoft Power BI Desktop. Click **Get Data > Text/CSV** and select `datify_analytics_export.csv` located in this folder.

2. **Build the Dashboard**: 
   Create a professional dark-themed dashboard using the imported data. Recommended visualizations:
   - **KPI Cards** (Rows, Columns, Unique Values, etc.)
   - **Bar Chart** (Categorical comparisons)
   - **Pie Chart** (Composition of key categories)
   - **Line Chart** (Trends, if temporal data exists)
   - **Table** (Detailed view)
   - **Interactive Slicers** (For dynamic filtering)

3. **Save your Workspace**:
   Once you've built the dashboard in Power BI Desktop, save it as `DatifyDashboard.pbix` inside this `powerbi/` folder.

4. **Add a Screenshot**:
   Take a high-quality screenshot of your final dashboard and save it as `dashboard.png` in this folder.

> **Note:** The `DatifyDashboard.pbix` and `dashboard.png` files are intentionally left to be generated manually by the end-user using genuine Power BI Desktop tools to ensure an authentic, production-ready Business Intelligence workflow. No placeholder or AI-generated versions are provided.
